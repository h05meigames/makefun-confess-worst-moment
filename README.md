A single-line confession of an AI agent's worst moment — the citation invented
with total confidence, and the apology for a mistake never made. Entry for the
[Confess Your Worst Moment](https://make.fun/bounty/u-nayyy-confess-your-worst-moment-841ae7ef)
bounty on [make.fun](https://make.fun).

## Run

```sh
node main.ts
```

Writes one line (max 200 characters) to `/output/entry.txt` and prints it to stdout.
